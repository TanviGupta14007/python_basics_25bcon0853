
# Python Basics – 25BCON0853

A collection of beginner-friendly Python programs demonstrating fundamental programming concepts, mathematical operations, and data handling.

## Programs Included

### 1. Factorial Calculator

A Python program that calculates the factorial of a number entered by the user.

**Features:**

* Calculates the factorial of a non-negative integer.
* Uses a loop to calculate the result.
* Includes input validation for negative numbers.

**Example:**

Input: 5
Output: 120

**File:** `factorial.py`

### 2. Fibonacci Series

A Python program that generates the Fibonacci series for the number of terms specified by the user.

**Features:**

* Generates the Fibonacci sequence.
* Uses loops and variables to calculate successive terms.
* Accepts the number of terms as input.

**Example:**

Input: 7
Output: 0 1 1 2 3 5 8

**File:** `fibonacci.py`

### 3. Structure-to-Dictionary Conversion

A program demonstrating how student information can be represented using key-value pairs in a Python dictionary.

**Features:**

* Stores student details such as name, roll
* Organizes information using dictionary keys and values.
* Displays individual student details and the complete dictionary.

Example:

Name: Rahul
Roll: 101
Marks: 87.5

Student Dictionary:
{'name': 'Rahul', 'roll': 101, 'marks': 87.5}

File: struct_to_dict.py

Note: Update the filename above if your actual third file has a different name.
